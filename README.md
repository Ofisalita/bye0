# bye0

platform aggregator for playing and sharing music from multiple streaming platforms on a single device 😉

# The Why

multiple friends with multiple streaming platforms sharing a single "aux cord" have trouble managing the queue as these services don't play nice with each other. 

# The How

we'd like a solution that doesn't require everyone to have an account on a single service, easily shareable on a single party. this should make music selection and queue managing effortless.
